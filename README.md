# VLAN-Outage-The-Pruned-Trunk

Establish the outage scope
  Compare two paths that share the same cable and trunk ports.

Rule out the network edge
  Confirm addressing, physical status, and access VLAN membership before touching the trunk.

Compare the trunk endpoints
  A trunk can be operational while carrying only part of the intended VLAN set.

Repair and prove
  Restore the missing VLAN on one endpoint without changing the working edge configuration.
